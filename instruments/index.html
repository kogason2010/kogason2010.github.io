The instruments

Every instrument in the lab, each in its own folder with its own model.js. The site loads those files as they are, so you can change one instrument on its own: look at it here, offline, then upload the file to GitHub.

  1. Open an instrument below. It opens from your disk in this browser; no internet needed.
  2. Edit its model.js in VS Code (instruments/<name>/model.js) and save.
  3. Refresh its page (F5) to see the change. Click any part to find the line that makes it.
  4. Upload the changed model.js to the same folder on GitHub. The live site updates a minute or two later.
See instruments/README.md for the details. The viewer uses three.js r128 (MIT licence, in viewer/).
